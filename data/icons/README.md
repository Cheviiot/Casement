# Remote operating-system icons

The bundled OS and distribution marks are selected from
[Devicon](https://github.com/devicons/devicon) revision
`32fe1d3b3f36ad11f90ab94f7db59738139c2bf6`. Devicon is distributed under the MIT license in
`LICENSE.devicon`; product names and logos remain trademarks of their owners.

Included upstream files:

- `casement-os-windows.svg` ← `icons/windows11/windows11-original.svg`
- `casement-os-linux-symbolic.svg` ← `icons/linux/linux-plain.svg`
- `casement-os-ubuntu.svg` ← `icons/ubuntu/ubuntu-original.svg`
- `casement-os-debian.svg` ← `icons/debian/debian-original.svg`
- `casement-os-fedora.svg` ← `icons/fedora/fedora-original.svg`
- `casement-os-arch.svg` ← `icons/archlinux/archlinux-original.svg`
- `casement-os-opensuse.svg` ← `icons/opensuse/opensuse-original.svg`
- `casement-os-mint.svg` ← `icons/linuxmint/linuxmint-original.svg`
- `casement-os-nixos.svg` ← `icons/nixos/nixos-original.svg`

ALT Linux uses the generic Linux mark because Devicon has no ALT icon and the logo available in
ALT's local hicolor theme is CC-BY-SA and text-heavy at card size. Casement does not redistribute
it or silently mix an incompatible asset license into the application.
