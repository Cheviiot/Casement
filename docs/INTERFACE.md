# Интерфейс Casement

## Сценарии

Casement нужен для подключения к нескольким своим компьютерам. Главная страница —
короткий устойчивый список подключений. На ней нет настроек этого компьютера, поля
адреса, фильтра списка, фонового обнаружения и повторного списка тех же устройств.

1. **Подключиться к своему компьютеру.** Нажать строку сохранённого подключения.
   При необходимости ввести пароль; после входа открывается экран компьютера.
2. **Добавить компьютер.** «Добавить» → «В локальной сети» или «По адресу».
   Обнаружение работает только на странице локальной сети. Выбор устройства или
   сохранение адреса возвращает к списку подключений; вход — отдельное действие.
3. **Изменить подключение.** Кнопка параметров в строке открывает одну форму.
   Изменения применяются вместе по «Сохранить». Ошибка не теряет введённые данные.
4. **Управлять удалённым экраном.** Во время сеанса доступны экран, звук, файлы,
   полноэкранный режим и завершение. Выбор монитора показывается только при наличии
   нескольких мониторов. Дополнительная страница не обрывает сеанс.
5. **Передать файл.** Страница файлов позволяет выбрать файлы этого компьютера или
   скачать файлы удалённого. Передачи показывают состояние и прогресс; одновременные
   одноимённые файлы сохраняются независимо, существующие файлы не заменяются.
6. **Настроить доступ к своему компьютеру.** «Настройки» содержит приём подключений,
   пароль, доверенные устройства, адрес и ключ этого компьютера. На главной эти
   сведения не повторяются. Сведения о программе находятся здесь же.

## Страницы

```text
Подключения
├── Добавить
│   ├── В локальной сети
│   └── По адресу
├── Параметры подключения
│   └── Ключ компьютера
├── Сеанс
│   ├── Файлы
│   │   └── Выбрать файлы для отправки
│   └── Монитор
└── Настройки
    ├── Пароль доступа
    ├── Доверенные устройства
    ├── Ключ устройства
    └── О программе
```

Пароль входа, изменившийся ключ, подключение, переподключение и ошибка соединения —
состояния одной страницы сеанса. Они не добавляют уровни навигации. Все остальные
экраны — страницы NavigationView; диалогов и выпадающих меню нет.

## Поведение и состояния

- Строка подключения соединяет с компьютером; кнопка параметров только открывает
  параметры. Одно и то же действие не повторяется несколькими кнопками рядом.
- Добавленные подключения не прыгают по списку после использования. Сортировка по
  имени, затем адресу; текстовый поиск и избранное для короткого списка не нужны.
- LAN-обнаружение исключает собственный компьютер, сводит адреса одного ключа в
  одно устройство и отмечает уже добавленные. Данные объявления не подменяют
  доверенный ключ сохранённого компьютера.
- Системы dual-boot различаются ключом и подписью ОС. Одинаковый адрес не объединяет
  «GEM12 · ALT Workstation» и «GEM12 · Windows»; иконка показывает семейство системы.
- Отсутствие объявления mDNS не означает «не в сети»: сохранённые компьютеры могут
  быть доступны по Tailscale. Не показывать выдуманную доступность.
- Для каждой асинхронной операции предусмотрены ожидание, успех, ошибка и уход со
  страницы. Медленный ответ старой операции не меняет новую страницу.
- Пароль сохраняется в фоне; повторное сохранение на время операции выключено.
  Поля очищаются после успеха или ухода. Ошибка оставляет возможность повторить.
- Ошибку чтения пароля или доверенных нельзя показывать как отсутствие данных.
  После восстановления файла повторное чтение возвращает сохранённое состояние.
- Удаление подключения и отзыв доверия обратимы через «Отменить». Смена адреса
  сбрасывает привязку ключа только после успешного сохранения.
- Назад из сеанса завершает соединение. Открытие файлов или мониторов поверх сеанса
  его сохраняет; локальные клавиши отпускаются при потере фокуса экрана.
- Скачивание можно отменить в строке файла. Уход со страницы файлов отменяет её
  передачи и очередь; открытие выбора файлов поверх неё сохраняет операции.
  Отмена удаляет временный файл, незавершённый файл не появляется в «Загрузках».
- Поля вокруг изображения не принимают нажатия. Перетаскивание, начатое на экране,
  завершается и при отпускании за его краем; кнопка не остаётся зажатой.
- Виртуальный рабочий стол выбирает стандартное разрешение при подключении. Размер
  окна меняет локальный масштаб, но не перенастраивает живой видеопоток и не рвёт сеанс.
- Подтверждение нового устройства не возвращается. Изменение известного ключа
  по-прежнему останавливает соединение и требует решения владельца.

## Оформление и проверка

Нативные GTK 4 / Libadwaita, системная светлая или тёмная тема и акцент. Единые
отступы 12/18/24/32, компактные смысловые группы, один главный акцент на страницу.
Заголовок не повторяется крупным hero в той же странице. Иконки обозначают действия
и сущности; декоративные показатели, карточки-пустышки и поясняющие абзацы не нужны.

Все страницы проверяются под headless Broadway: обычное и узкое окно, светлая и
тёмная тема, пустые списки, длинные имена, ошибки и ожидание. Проверки не открывают
окон и не посылают клавиатурный ввод в рабочий сеанс владельца. Форматирование,
clippy, unit/loopback tests и сборки Linux/Windows остаются обязательными.
